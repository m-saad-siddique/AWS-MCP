# Changelog

## Initial public release

- Local stdio MCP and browser approval dashboard for AWS CLI profiles.
- Manual/scoped automatic policies, protected profiles, MFA reuse, and macOS
  Keychain persistence for temporary sessions.
- Direct or manually masked AWS output delivery.
- Managed Session Manager tunnels and PostgreSQL/MySQL queries for private RDS.
- Durable request history, timelines, filtering, and JSON export across restarts.
- Command builder, multi-profile drafts, grouped queues, selected/all/individual
  approvals, sequential execution, failure stopping, and stop-after-current.
- Synthetic integration/browser fixtures and public setup documentation.
